# Puzzles

### ▶ [Play the puzzles on my GitHub Pages](https://tuongphantrue.github.io/puzzles/)

A Kindle-friendly HTML5/JavaScript puzzle collection based on the 2013
`medmunds/puzzles` port of Simon Tatham's Portable Puzzle Collection.

The GitHub Pages deployment intentionally uses the last playable historical
`gh-pages` version from before the later site-migration redirects were added.
